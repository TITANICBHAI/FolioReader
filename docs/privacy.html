Privacy

Privacy Policy

Draft for review before publication. This page describes the current Android implementation and should be updated if the release build, analytics, advertising, hosting, or third-party services change.

What Folio stores

Folio stores reading state, vocabulary, cached definitions, preferences, and related app data locally on your Android device. The current project does not require a central account for these core features.

PDF and document content

Documents selected for reading are processed on the device for PDF rendering, text extraction, OCR and vocabulary assistance. The app does not need to upload ordinary PDF content to provide the core reader workflow.

Translation

Folio can download an ML Kit language model for on-device translation. After the model is available, translation can be performed without sending the text to a remote translation service.

AI explanations

AI explanations are optional. When enabled, the app can use a Gemini API key supplied by the user to request an explanation. Text sent for this feature should be treated as data that leaves the device and is processed by the configured AI service.

Classroom mode

Classroom mode can use Android Nearby Connections for shared activities between nearby devices. The Android permissions required by that functionality are separate from the core reading workflow.

Permissions

The Android project requests permissions needed for the features you enable, including permissions associated with nearby connections and audio-related functionality. Keep the published permission disclosures synchronized with the release build and Google Play Data safety declarations.

Data retention and deletion

Local reading state and vocabulary remain on the device until removed by the user or the app. The data deletion page explains the available removal path.
