FAQ

Questions before you open a PDF.

Does Folio Reader work offline?
Core reading, vocabulary storage, the built-in dictionary, OCR and downloaded on-device translation can work without an internet connection. Optional features may require network access.
Can Folio read scanned PDFs?
Yes. Scanned PDFs can be processed with on-device OCR so their text can be used in the reader and vocabulary workflow.
How does Smart Highlighting work?
When enabled, Folio evaluates the words on the current page and highlights words it considers challenging according to the configured highlight density.
Does Folio translate to Hindi?
Yes. The app can download an English-to-Hindi ML Kit model for on-device translation. The selected target language and model status are managed in Settings.
Does Folio use AI?
AI explanations are optional. The app can request Gemini explanations using an API key configured by the user. Core reading and vocabulary workflows do not depend on AI.
Can I export my vocabulary?
Yes. The vocabulary area provides export options, including Anki-compatible CSV and readable plain text.
Does Folio require an account?
The current Android project uses local storage for reading state and vocabulary and does not require a central user account for those workflows.
